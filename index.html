dplyr verbs intro + quiz

The core dplyr verbs form a grammar of data manipulation. Each verb does one thing well — and they chain together with the pipe %>% or |>.

filter()
subset rows
Keep rows that match a condition. Like WHERE in SQL.
filter(df, height > 180)
select()
pick columns
Choose variables by name or range. Drop the rest.
select(df, name, age, city)
mutate()
create / modify columns
Add new variables or transform existing ones. Keeps all original columns.
mutate(df, bmi = weight / height^2)
arrange()
order rows
Sort rows by one or more columns. Use desc() for descending.
arrange(df, age, desc(score))
summarize()
aggregate
Reduce many rows to a single summary (or one per group).
summarize(df, mean_age = mean(age))
group_by()
group operations
Split data into groups; affects verbs that follow (summarize, mutate, etc.).
group_by(df, department)

🔗 chain with pipes %>% |>

# using the magrittr pipe (classic dplyr style) flights %>% filter(dest == "LAX") %>% group_by(carrier) %>% summarise( avg_delay = mean(dep_delay, na.rm = TRUE), count = n() ) %>% arrange(desc(avg_delay)) # native pipe (R ≥ 4.1) works too mtcars |> filter(cyl == 4) |> select(mpg, wt, hp) |> mutate(power_to_weight = hp / wt)
⚡ dplyr verbs always take a data frame first, return a data frame. Use across() inside mutate() or summarise() for multiple columns.
